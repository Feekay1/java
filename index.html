History of JavaScript

JavaScript was created by Brendan Eich at Netscape
who made JavaScript the leading language for building modern web applications.



1995

  • JavaScript was created by Brendan Eich at Netscape.
  • It was built in just 10 days.
  • This standardization was done by ECMA International


1997

  • JavaScript became officially standardized as ECMAScript (ES1).
  • The goal was to make JavaScript work the same across all browsers.
  • This standardization was done by ECMA International.


2009

  • Node.js was introduced, bringing JavaScript to the server side.
  • Developers could now use one language for both both front-end and back-end.
  • It increased JavaScripts popularity as a full-stack language.


2015 (ES6)

  • ES6 introduced modern features like let, const, and arrow functions
  • JavaScript became more structured with classes and modules.
  • It marked the biggest upgrade in the languages history.


2015–Present

  • Frameworks like React, Angular, and Vue became widely used.
  • JavaScript expanded to mobile apps, desktop apps, and APIs.
  • It became one of the most popular programming languages in the world.
